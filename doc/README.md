## 書き方の決まり

- 日本語で書く。各資料の先頭に「目的」「対象読者」を書く。
- **コードを正**にする。ファイル・関数・定数の名前はコードのとおりに書き、値(時間・回数・上限)はコードの定数から写す。
  定数を変えたら資料も直す(どの定数かは各資料に書いてある)。
- 図は mermaid(`flowchart` / `erDiagram` / `sequenceDiagram`)。GitHub でそのまま表示される。
- 資料どうしのリンクは相対パス(`[04](04_API仕様.md)`)。リンク切れは `08_開発ガイド.md` の「資料のリンクの確認」で確かめる。
- 未実装・未決定のものは「未実装」「未決定」と明記する(できていることと混ぜない)。
- テーブル定義(03付録)は手で直さない。スキーマの JSDoc を直してから `pnpm db:doc` で作り直す。
- 変更履歴は `CHANGELOG.md`(`## [Ver. x.y.z] - 日付`)に書き、資料には書かない。
